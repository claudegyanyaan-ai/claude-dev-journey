## System prompt (new concept)

Explained the `system` vs. `messages` distinction: system = standing instructions same on every call; messages = the actual per-call input. Why it matters: reliable format enforcement (only pure JSON, no preamble) so code can safely call `json.loads()` on the reply.

User's first attempt at drafting the system prompt merged the general rule with a specific example input — had to explicitly separate "the rule that never changes" (system) from "the specific input" (user message) via guided questions, then gave a full worked example when the user said they weren't following.

Target extraction shape agreed: `[{"item": ..., "quantity": ..., "amount": ...}]` from messy grocery-list-style text like `"milk 1 ltr 100rs, flour 2kg 200rs"`.
