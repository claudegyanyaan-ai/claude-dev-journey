## Big discovery: pre-existing Desktop-level git repo

While removing the 4 inner `.git` folders (Step A of consolidation), `git status`
run inside `01-hello-claude-code` surfaced a **different, pre-existing git repo
rooted at the user's entire Desktop** (`C:/Users/VARUN TYAGI/Desktop`) — it had
been silently shadowed by the inner project repos the whole time.

Investigated carefully before proceeding (this could have been serious — Desktop
contains personal folders like `Financial/`, `Personal/`, `Pictures/`, `Study/`,
`Work/`):
- `git remote -v` → already connected to a **different** GitHub account/repo:
  `https://github.com/varuntyagiai/VT_KN_GIT_learning.git` — almost certainly
  leftover from an earlier, unrelated git-learning exercise.
- `git log --oneline` → only 2 commits ("first commit", "second commit").
- `git ls-files` (run from repo root) → only ever tracked **one file**, `abc.md`
  (since deleted from disk). Confirmed clean — nothing personal or sensitive

Resolution: left the Desktop-level repo completely untouched (no need to
delete/fix it). Proceeded to `git init` a **new, separate, nested repo** inside
"Claude dev journey" itself — this automatically takes priority over the
Desktop repo for everything inside it, restoring full isolation without
touching the old repo at all.
